# FAA / EASA Part 121 Continuous Airworthiness

## Turbine Engine Health Monitoring Parameters
- **Exhaust Gas Temperature (EGT) Margin**: The buffer between operating takeoff EGT and the redline certification limit.
- **Rotor Vibration (ips)**: In-phase vibration velocity for N1 (low-pressure fan) and N2 (high-pressure core) shafts. Must remain $< 1.0$ inches per second.
